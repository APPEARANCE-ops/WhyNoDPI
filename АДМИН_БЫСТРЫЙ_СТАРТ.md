## Шаг 1. База данных (5 минут)

1. [neon.tech](https://neon.tech) → **Sign up** (через GitHub) → **New Project**.
2. Имя `whynodpi`, регион **Frankfurt**, остальное по умолчанию → **Create**.
3. Откройте **SQL Editor**, вставьте целиком файл `prisma/schema.postgres.sql`
   из проекта и нажмите **Run**. Должно появиться «Success».

   Это создаёт 4 таблицы — больше никаких действий с базой не нужно.

4. Нажмите **Connect** и скопируйте строку подключения:
   - с включённым тумблером **Connection pooling** — она с `-pooler`, это `DATABASE_URL`;
   - direct-строка (без `-pooler`) вам больше не понадобится, раз таблицы уже созданы.

   В конце pooled-строки допишите параметры:
   `?sslmode=require&pgbouncer=true&connection_limit=1`
   (замените то, что стоит после `?`).

## Шаг 2. Vercel (5 минут)

1. [vercel.com](https://vercel.com) → **Add New → Project** → выберите репозиторий
   с проектом (или загрузите папку).
2. Framework Preset определится сам — **Next.js**, команду сборки не меняйте:
   она берётся из `vercel.json` и уже делает `prisma generate` под Postgres.
3. **Environment Variables** — добавьте три:

| Name | Value |
|---|---|
| `DATABASE_URL` | pooled-строка из шага 1 |
| `ADMIN_PASSWORD_HASH` | строка из таблицы выше |
| `TELEMETRY_PEPPER` | строка из таблицы выше |

4. **Deploy** (2–3 минуты).

## Шаг 3. Проверка (1 минута)

1. Откройте `https://ваш-проект.vercel.app/api/health` — должно быть:


   Если `"database": "down"` — проверьте `DATABASE_URL` в Vercel (и нажмите
   Redeploy, если меняли переменную).

2. Откройте `https://ваш-проект.vercel.app` → введите пароль `cZ5vmkVWWLJtQ3Awrn`.

Всё — вы админ. Панель пустая, потому что клиенты ещё не настроены на неё.

## Шаг 4. Собрать WhyNoDPI для пользователей

Теперь, когда известен адрес панели, соберите версию, в которую этот адрес уже вшит.

```powershell
cd путь\к\проекту\download\WhyNoDPI
.\Build-User.cmd https://ваш-проект.vercel.app
```

или, если .cmd не запускается:

```powershell
powershell -ExecutionPolicy Bypass -File .\Build-User.ps1 -PanelUrl https://ваш-проект.vercel.app
```

На выходе — папка `dist\WhyNoDPI-User-<дата>` и архив `dist\WhyNoDPI-User-<дата>.zip`.

Внутри:

- `WhyNoDPI.exe` — с уже вшитым адресом панели, карточки «Сервер статистики» в
  настройках нет (пользователю нечего настраивать);
- `КАК_ПОЛЬЗОВАТЬСЯ.txt` — три шага: скачать Flowseal, запустить от админа, выбрать папку.

**Раздавайте именно ZIP**, а не EXE: внутри инструкция.

> Разница между сборками: обычная (`Build-EXE.ps1`) — для вас, адрес панели
> настраивается в интерфейсе; пользовательская (`Build-User.ps1`) — с вшитым
> адресом и без лишних настроек.

## Что вы увидите в панели

Как только кто-то запустит ваш EXE:

- **В сети сейчас** — сколько людей работает прямо сейчас (heartbeat раз в 60 с,
  онлайн-окно 150 с);
- **Всего пользователей**, **Новые сегодня**, **Активны за 24 часа**;
- **График** онлайна за сутки;
- **Версии / ОС / стратегии** — распределения;
- **Последние клиенты** — таблица с поиском, фильтром и экспортом в CSV.

Идентификатор установки — случайный GUID; на сервере хранится только его SHA-256
с вашим `TELEMETRY_PEPPER`. Ни IP, ни путей, ни паролей приложение не отправляет.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `/api/health` → `"database": "down"` | неверный `DATABASE_URL`; в строке должен быть `-pooler`; после правки — Redeploy |
| Вход: «Пароль не настроен на сервере» | `ADMIN_PASSWORD_HASH` не добавился; добавьте и нажмите Redeploy |
| Вход: 429 | 5 неудачных попыток → блокировка на 10 минут |
| В панели 0 пользователей | никто не запускал вашу сборку, либо она собрана со старым адресом — пересоберите через `Build-User.ps1` |
| Сборка на Vercel падает на `prisma generate` | проверьте, что `vercel.json` использует `npm run build:vercel` |

## Безопасность — две вещи

1. Пароль из этого файла знаете только вы. Если файл куда-то передавали —
   смените пароль (новый хеш → обновите переменную в Vercel → Redeploy).
2. `DATABASE_URL` содержит пароль от базы. Не выкладывайте её в публичный
   репозиторий; `.env` уже в `.gitignore`.
