# WhyNoDPI

**WhyNoDPI** — приложение для Windows (WPF), которое управляет движком Zapret из одного окна.

**Автор приложения: Xcuv** · версия интерфейса 1.3

## Что умеет

- Запускает `bin\winws.exe` напрямую с параметрами выбранного профиля General.
- Даёт выбрать основной профиль или вариант ALT.
- Останавливает только собственный процесс `winws.exe`.
- Проверяет наличие WinDivert и конфликтующей службы `zapret`.
- Сохраняет диагностику запуска в `%LOCALAPPDATA%\WhyNoDPI\logs`.
- Может оставить сетевой движок работать после закрытия окна.
- Само следит за состоянием движка: если `winws.exe` завершится, интерфейс это покажет.
- Проверяет доступность YouTube, Discord и Telegram с задержкой в миллисекундах.

## Интерфейс

- Сайдбар с разделами: Главная, Стратегии, Telegram · VPN, Журнал, Настройки.
- Hero-карточка состояния: включён ли движок, какой профиль активен, сколько он работает.
- Автоподбор стратегий с прогрессом, счётом по каждому профилю и кнопкой отмены.
- Журнал с уровнями (информация, успех, предупреждение, ошибка), поиском и фильтрами.
- Статус-бар внизу: состояние движка, профиль, время последней проверки.
- Горячие клавиши: `F5` — проверить сервисы, `Ctrl+1…5` — переключение разделов.
- Тёмная тема для всех контролов (поля, списки, прокрутка, переключатели) и
  тёмный заголовок окна Windows 11, корректные пропорции на HiDPI-экранах.
- Ошибки, подтверждения и вопросы показываются в собственных диалогах, а не в
  системных светлых окнах.
- Необработанные ошибки пишутся в `%LOCALAPPDATA%\WhyNoDPI\logs\crash-*.log`, а
  второй экземпляр приложения не запускается и предупреждает об этом.

## Работа без BAT при запуске

При первом выборе папки Flowseal приложение один раз читает файлы профилей General как обычный текст и импортирует параметры в JSON-кэш `%LOCALAPPDATA%\WhyNoDPI\profiles`. После импорта эти исходные файлы больше не нужны. При каждом включении WhyNoDPI запускает непосредственно `bin\winws.exe` с аргументами из кэша — без `cmd.exe`, BAT-процесса и временных скриптов. Файл `utils\game_filter.enabled` читается в формате Flowseal (`mode=all/tcp/udp`, `tcp=...`, `udp=...`), чтобы сохранить выбранные диапазоны портов.

## Что понадобится

- Windows 10/11 x64.
- .NET 10 SDK для сборки из исходников.
- Официальный пакет Flowseal: https://github.com/Flowseal/zapret-discord-youtube/releases/latest

Распакуй Flowseal в отдельную папку, желательно с коротким путём без пробелов и кириллицы, например `C:\zapret-flowseal`. В настройках WhyNoDPI укажи эту папку. В ней должны находиться `bin\winws.exe`, папка `lists` и оригинальные профили General для первоначального импорта.

После первого импорта профильные файлы можно удалить или не использовать, но папки `bin` и `lists` должны остаться. В `bin` находятся сам движок, DLL и драйвер WinDivert; один EXE интерфейса не может заменить сетевой драйвер и необходимые списки.

Для WinDivert требуются права администратора. Если служба Windows `zapret` уже работает или запущен другой `winws.exe`, WhyNoDPI не запускает второй экземпляр. Останови внешний обход через программу, которая им управляет.

## Сборка одного EXE

Открой `WhyNoDPI.slnx` или `WhyNoDPI.csproj` в Visual Studio с .NET 10 SDK. Либо запусти `Build-EXE.ps1` в PowerShell. Скрипт сам восстанавливает пакеты, публикует приложение в один EXE и открывает папку результата. Если в Windows настроен локальный прокси `127.0.0.1:8080`, скрипт временно выключает его только на время NuGet restore и возвращает исходное состояние после сборки. Для ручной публикации автономного приложения Windows x64 выполни в терминале:

```powershell
dotnet restore .\WhyNoDPI.csproj -r win-x64 -p:NuGetAudit=false
dotnet publish .\WhyNoDPI.csproj -c Release -r win-x64 --self-contained true --no-restore -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\publish
```

Готовый интерфейс приложения: `publish\WhyNoDPI.exe`. Внешний пакет Flowseal всё равно нужен для `winws.exe`, WinDivert DLL/драйвера и файлов списков. Сам WhyNoDPI публикуется одним автономным EXE.

## Обновления

Настройки → «Обновления» → «Проверить». Приложение смотрит две вещи:

- **WhyNoDPI** — спрашивает у вашей панели (`/api/version`), какая версия актуальна;
- **пакет Flowseal** — берёт последний релиз с GitHub (`Flowseal/zapret-discord-youtube`).

Если вышло новее — строка подсвечивается жёлтым и появляется кнопка «Скачать»
(для WhyNoDPI) или «Релиз Flowseal». Проверка идёт и сама при запуске, не чаще
раза в 30 минут; при находке показывается уведомление.
## Статистика в админ-панели

WhyNoDPI умеет раз в минуту отправлять на вашу панель анонимный heartbeat —
благодаря этому в панели видно, сколько людей запускают приложение прямо сейчас.

1. Разверните панель (проще всего на Vercel — см. `README-VERCEL.md` в корне проекта).
2. В приложении: **Настройки → «Сервер статистики»** → вставьте адрес панели,
   нажмите «Проверить связь», затем «Сохранить».
3. Галочка «Отправлять анонимную статистику» должна быть включена.

Отправляются только случайный номер установки, версия приложения, строка ОС и имя
профиля. Ни IP, ни путей, ни паролей, ни секретов прокси.

## Telegram: MTProto и VPN

- Встроена страница Telegram с переходом к каналу [@mtp4tg](https://t.me/mtp4tg).
- Можно импортировать конкретные ссылки `t.me/proxy?...` или `tg://proxy?...` и передать их Telegram Desktop для подтверждения подключения.
- Секрет прокси не сохраняется в настройках и не записывается в журнал.
- Кнопка VPN открывает системные настройки Windows; приложение не включает неизвестный VPN-сервис и не подменяет VPN прокси.

Публичные прокси могут менять адрес и статус. Подключайтесь только к серверам, которым доверяете.
