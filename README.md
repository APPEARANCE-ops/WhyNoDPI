# WhyNoDPI

Небольшое WPF-приложение для Windows, которое позволяет управлять профилями Zapret от Flowseal из одного окна — без необходимости каждый раз открывать BAT-файлы вручную.

**Автор WhyNoDPI: Xcuv**

## Что умеет приложение

- Запуск и остановка выбранного профиля `general*.bat`.
- Скрытый запуск без отдельного окна командной строки.
- Поиск профилей в выбранной папке Flowseal.
- Автоматическая проверка профилей по доступности YouTube, Discord и Telegram Web.
- Журнал событий и отображение состояния движка.
- Быстрый переход к YouTube, Discord и Telegram.

## Исходный код

Архив проекта Visual Studio (WPF): **WhyNoDPI-Source.zip** — будет опубликован отдельным файлом в этом репозитории.

## Что понадобится

- Windows 10 или 11, x64.
- Visual Studio с workload «Разработка классических приложений .NET».
- .NET 10 SDK.
- Официальный пакет Flowseal: [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube/releases/latest).

Скачай и распакуй пакет Flowseal отдельно. В настройках WhyNoDPI укажи папку, в которой находятся `service.bat`, `bin\winws.exe`, `lists` и файлы `general*.bat`.

Открой `WhyNoDPI.slnx` или `WhyNoDPI.csproj` в Visual Studio и собери проект в конфигурации Release для x64. Для работы WinDivert требуются права администратора.

## Автоматический подбор стратегии

Приложение последовательно проверяет найденные профили и оставляет профиль с лучшим результатом проверки. Проверка выполняется по HTTPS-доступности контрольных адресов. Она не гарантирует воспроизведение видео, стабильную работу голосового чата или UDP в Discord — результат зависит от провайдера и сети.
