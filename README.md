# WhyNoDPI

**WhyNoDPI** — WPF-приложение для Windows, которое помогает управлять профилями Zapret от Flowseal из одного окна.

**Автор: Xcuv**

> Проект развивается. Возможности, помеченные как «планируется», ещё не считаются реализованными или проверенными.

## Возможности текущей версии

- Запуск и остановка выбранного профиля `general*.bat`.
- Скрытый запуск профиля без отдельного окна командной строки.
- Поиск профилей в выбранной папке Flowseal.
- Проверка доступности YouTube, Discord и Telegram Web.
- Журнал событий и отображение состояния движка.
- Быстрый переход к YouTube, Discord и Telegram.

## Планируемые возможности

- **Пользовательский режим:** простое управление Zapret, профилями и проверками сервисов.
- **Режим разработчика:** подробные журналы в реальном времени, диагностика процессов, профилей и WinDivert, экспорт отчёта.
- **WinDivert:** проверка состояния и корректная обработка конфликтов; драйвер не должен отключаться или удаляться, пока он нужен Zapret.
- **Автообновление:** проверка версии, загрузка официального выпуска, проверка SHA-256, отложенная установка, сохранение настроек и возможность отката.
- **Отправка жалоб:** защищённая передача обращения администратору только с согласия пользователя, предварительный просмотр и очистка диагностических данных, серверные ограничения против спама.

## Системные требования

- Windows 10 или Windows 11, x64.
- Visual Studio с рабочей нагрузкой «Разработка классических приложений .NET».
- .NET 10 SDK для сборки из исходников.
- Оригинальный пакет Flowseal / Zapret.

## Установка и настройка

1. Скачайте оригинальный пакет Flowseal со страницы [релизов Flowseal](https://github.com/Flowseal/zapret-discord-youtube/releases/latest).
2. Распакуйте его отдельно от WhyNoDPI.
3. В настройках WhyNoDPI укажите папку, в которой находятся `service.bat`, `bin\\winws.exe`, `lists` и профили `general*.bat`.
4. Выберите профиль и запустите его.
5. Если операция требует повышенных прав, запустите приложение от имени администратора.

Не скачивайте сборки Zapret из неизвестных источников.

## Сборка

Откройте решение или файл проекта WhyNoDPI в Visual Studio, выберите конфигурацию **Release** и платформу **x64**, затем выполните сборку.

Если файл решения или проекта отсутствует в скачанном архиве, проверьте состав исходников и используйте актуальный проект из репозитория. Не создавайте случайный пустой проект вместо исходного приложения.

## Возможные ошибки и способы исправления

| Ошибка | Возможная причина | Что проверить |
|---|---|---|
| Не найдена папка Flowseal | Указан неверный путь | Выберите папку с оригинальной установкой Flowseal |
| Не найден `winws.exe` | Пакет распакован не полностью или выбран не тот каталог | Проверьте наличие `bin\\winws.exe` |
| Профили не найдены | Нет файлов `general*.bat` | Проверьте комплектность пакета Flowseal |
| Отказано в доступе | Не хватает прав | Запустите приложение с необходимыми правами администратора |
| Ошибка WinDivert | Драйвер отсутствует, занят или заблокирован | Проверьте комплектность Flowseal, состояние драйвера и конфликты с другими экземплярами; не удаляйте драйвер вручную во время работы Zapret |
| Zapret запускается, но сервисы не открываются | Профиль не подходит для сети или провайдера | Остановите текущий профиль и попробуйте другой доступный профиль |
| Проверка сервиса показывает ошибку | Сервис или контрольный адрес временно недоступен | Повторите проверку; учитывайте, что HTTPS-проверка не гарантирует работу видео, UDP или голосового чата |
| Приложение не запускается | Повреждены файлы или отсутствует необходимая среда выполнения | Проверьте файлы приложения и установите требуемый .NET Runtime, если он не включён в сборку |
| Сборка завершается ошибкой | Не установлен SDK или рабочая нагрузка Visual Studio | Установите .NET 10 SDK и workload для классических приложений .NET |
| Обновление не загружается | Нет соединения с GitHub или сервер временно недоступен | Повторите попытку позже или используйте проверенный официальный выпуск |
| Проверка обновления не пройдена | Файл повреждён или контрольная сумма не совпала | Отмените установку и загрузите выпуск заново из официального источника |
| Жалоба не отправляется | Сервер недоступен, запрос ограничен антиспамом или нет соединения | Проверьте подключение и повторите отправку позже; не отправляйте одну жалобу многократно |

## Безопасность и конфиденциальность

- Не отключайте Защитник Windows и другие средства защиты ради запуска приложения.
- Не устанавливайте файлы из неизвестных источников.
- Не публикуйте в открытых Issues пароли, токены, cookie, личные данные и необработанные журналы.
- Диагностические данные для отправки администратору должны предварительно очищаться и передаваться только после согласия пользователя.
- Секретные ключи серверной отправки жалоб и уведомлений нельзя хранить внутри EXE или в публичном репозитории.
- Обновления должны устанавливаться только после проверки подлинности источника и целостности пакета.

## Ограничения проверки сервисов

Проверка доступности YouTube, Discord и Telegram Web выполняется по сетевым контрольным адресам. Успешная HTTPS-проверка не гарантирует воспроизведение видео, работу UDP, голосового чата или всех функций сервиса. Результат зависит от сети, провайдера и выбранного профиля.
